# Working with SCDM data

Use the bundled [SCDM reference index](references/index.md) to find a table by name or TabID, then read its Markdown reference. Resolve these paths relative to this skill directory. If only a variable name is known, search the bundled Markdown files for its heading.

The references contain SCDM 8.2.2 table and variable definitions. Read only the tables needed for the question; each contains its own definitions and guidelines. Answer from that text, including applicable missing-value rules and caveats.
